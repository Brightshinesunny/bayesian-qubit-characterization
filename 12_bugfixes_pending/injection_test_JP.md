# モデル誤設定の注入試験 — 総括

超伝導共振器・キュービット特性化において、**モデル誤設定（model misspecification）がパラメータ推定に与える系統バイアス**を、参値が既知の合成データで定量化した記録。

---

## 0. 本試験が答えようとする問い

実測データには参値がない。フィッティングが収束し残差が小さく見えても、それが**モデルが正しいからなのか**、それとも**モデルが誤っているのにそう見えるだけなのか**を区別する手段がない。

注入試験（injection test）はこの区別を可能にする。参値が既知の信号に系統効果を意図的に加え、その効果を**含まない**モデルでフィットする。そうすれば「どれだけ誤ったか」を百分率で言える。

本試験は三点を確認しようとした。

1. どのパラメータが誤設定に脆弱か
2. 効果ごとの寄与を分離できるか
3. 通常の診断指標（収束判定、残差）が誤設定を捉えるか

---

## 1. 物理的背景

### 1.1 反交差（avoided crossing）

キュービットと共振器が結合強度 $g$ で相互作用すると、両系の固有周波数が接近するとき**直接交差せず反発する**。量子力学の準位反発（level repulsion）であり、Jaynes–Cummings 模型の帰結である。

離調（detuning）$\delta = f_q - f_r$ に対し、二つの混成モード（hybrid mode）の周波数は

$$f_\pm = \frac{f_r + f_q}{2} \pm \frac{1}{2}\sqrt{\delta^2 + 4g^2}$$

$\delta = 0$ で間隔が最小値 $2g$ となる。**結合強度を直接測定する標準的方法**がこれである。

各混成モードが元のキュービット／共振器成分をどれだけ混ぜているかは**ホップフィールド係数（Hopfield coefficient）**、すなわち混成角で表される。

$$\sin^2\theta = \frac{1}{2}\left(1 - \frac{\delta}{\sqrt{\delta^2+4g^2}}\right), \qquad \cos^2\theta = 1 - \sin^2\theta$$

$\delta = 0$ なら $0.5/0.5$ で均等に混ざり、$|\delta| \gg g$ なら一方に完全に偏る。

### 1.2 トランスモンの磁束依存性

SQUID 構造の実効ジョセフソンエネルギーが外部磁束で変わるため、キュービット周波数は

$$f_q(\Phi) = (f_{q,\max} + E_C)\sqrt{|\cos(\pi\Phi)|} - E_C$$

$E_C$ は充電エネルギー（charging energy）。本試験では $f_{q,\max} = 5.150$、$E_C = 0.250$ GHz。

### 1.3 分散領域と共鳴領域

$|\delta| \gg g$ を**分散領域（dispersive regime）**という。両系がエネルギーを直接やりとりせず、互いの周波数をわずかに押し合うだけの状態である。キュービット読み出しにはこの領域を使うが、**$g$ を測定するには最悪の動作点**である。

本試験の初期設定 $\Phi = 0$ では

$$f_q(0) = 5.150,\quad \delta = +0.150 = 3.75g$$

ホップフィールド係数が $0.941 / 0.059$ に偏り、**ディップが事実上一つしか見えない**。そうなると観測量はディップ位置一つだけなのに未知数は $(f_r, g)$ の二つであり、**縮退（degeneracy）**する。この状態では $g$ の推定値はデータではなく prior が決める。

実際の反交差は

$$\sqrt{|\cos(\pi\Phi)|} = \frac{f_r + E_C}{f_{q,\max} + E_C} = \frac{5.25}{5.40} \;\Rightarrow\; \Phi = \pm 0.1059$$

本試験ではスキャンにより $\Phi = -0.1062$ を選択した。

### 1.4 線幅と品質係数

$\kappa$ は共振器の減衰率（decay rate）であり、ローレンツ曲線の半値半幅（HWHM）に対応する。品質係数との関係は

$$Q_l = \frac{f_r}{\kappa_{\rm total}}, \qquad \frac{1}{Q_l} = \frac{1}{Q_i} + \frac{1}{Q_c}$$

$Q_i$ は内部損失（材質欠陥など）、$Q_c$ は外部結合損失である。**$\kappa$ の誤差は $Q$ 系の報告値に直接伝播する。**

### 1.5 注入した三つの系統効果

**Fano 共鳴** — 理想的なローレンツ共振は「共振器へ入る経路が一つ」という仮定の上にある。実際の配線では共振器を経ずに漏れ出る直接経路が必ず混ざり、二経路が干渉すると線形が左右非対称に歪む。原子物理学で離散状態と連続状態の干渉を説明するために導入された概念である。

実装は**複素結合 Q** 方式を用いた（Khalil et al. 2012、Probst et al. 2015）。

$$\tilde{Q}_c = Q_c\cos\phi\, e^{-i\phi}, \qquad \phi = -\arctan(1/q)$$

非対称が位相回転として入るため、ベースラインが保存される。

> **注意** — 初期実装は $(q+x)^2/(1+x^2)$ を信号に掛けたうえで最大値で割っていた。この関数は $x \to \pm\infty$ ですでに 1 に収束するのに、最大値 $1+q^2$ で再度割ったため、**信号全体が $1/(1+q^2)$ 倍に潰れていた**（$q=2$ で 5 分の 1）。ベースライン 1 を前提とする標準モデルではいかなるパラメータ組合せでも合わせられない状態であり、これが最初の試験で $g$ 140 %、$\kappa$ 233 % の誤差を生んだ原因であった。

**TLS（Two-Level System、二準位系）** — 超伝導チップ表面や誘電体層の微小欠陥が小さなキュービットのように振る舞い、特定の固定周波数で共振器と弱く結合する。理論モデルにない狭い追加ディップを作る。これを真の反交差ピークと取り違えると、フィッティングが全く異なる値に収束する。

**baseline tilt** — 配線の周波数依存損失などにより伝送ベースラインが傾く現象。

## 2. 統計的背景

### 2.1 ベイズ推論

$$p(\theta \mid D) \;\propto\; p(D \mid \theta)\, p(\theta)$$

**事後分布（posterior）** $\propto$ **尤度（likelihood）** $\times$ **事前分布（prior）**。

本試験では一様 prior とガウス尤度を用いた。ガウス尤度は雑音 $\sigma$ を要求するが、**この $\sigma$ が誤っていれば尤度の幅が誤る**。§4.8 参照。

### 2.2 MCMC と自己相関時間

emcee はアンサンブルサンプラー（ensemble sampler）であり、複数の walker が互いの位置を参照しながら事後分布を探索する。

**自己相関時間（autocorrelation time）** $\tau$ は「鎖が独立な標本を一つ生むのに要するステップ数」である。有効標本数は $N_{\rm eff} \approx N/\tau$。

emcee の標準基準は

$$N > 50\tau \quad\Longleftrightarrow\quad \tau < N/50$$

であり、有効標本を 50 個以上確保せよという意味である。

**burn-in** は初期過渡区間を捨てること、**thinning** は相関した標本を間引くことである。

### 2.3 MAP と median

**MAP（Maximum A Posteriori）** は事後分布が最大となる点、すなわち実在する標本の一つである。

**median** は成分別中央値であるため、事後分布が非対称であったりパラメータ間相関が強いと、**どの標本とも一致しない点**になりうる。

本試験では `result` 辞書に標本と対数確率のキーがなく median で代用した。幸い事後分布が対称的で median 列と MAP 列が同一に出力されたが、これは MAP が計算されず fallback した結果であり、**検証されたものではない**。

### 2.4 識別可能性と縮退

**識別可能性（identifiability）** — データがパラメータを一意に決定できるか。

観測量の数より未知数が多い場合や、複数のパラメータ組合せが同じ予測を与える場合、**縮退（degeneracy）**する。縮退するとフィッシャー行列が特異（singular）になり逆行列が存在せず、MCMC は prior 境界まで流れていく。

§1.3 の分散領域がまさにこの状況である。

### 2.5 系統バイアスと統計誤差

**統計誤差**は雑音に由来し $\propto 1/\text{SNR}$ で減少する。
**系統バイアス**はモデル誤設定に由来し、**SNR に依存しない**。

したがって測定が精密になるほど系統バイアスが相対的に支配的になる。これが本研究方向の出発点である。

### 2.6 prior 境界への接触

推定値が prior 境界に張り付いた場合、その値は「データが示した値」ではなく**「探索範囲の端」**である。この状態の誤差はバイアスの大きさとして解釈できない。

最初の試験では $g = 0.09623$、$\kappa = 0.10000$ であり、上限は両方 $0.1$ であった。つまり **140 %・233 % という数値はバイアスの測定値ではなく箱の壁であった。**

## 3. 試験設定

### 参値

| パラメータ | 値 | 意味 |
|---|---|---|
| $f_r$ | 5.000 GHz | 共振器固有周波数 |
| $g$ | 0.040 GHz | キュービット–共振器結合強度 |
| $\kappa$ | 0.030 GHz | 共振器減衰率 |
| $\sigma$ | 0.015 | 白色雑音 |

$f_{q,\max} = 5.150$、$E_C = 0.250$、cable delay $\tau = 0.12$ は固定定数。

### 動作点

スキャンにより $\Phi = -0.1062$ を選択。

- ディップ 2 個が見える区間: $[-0.131, +0.131]$
- 最小間隔 $0.0780$ GHz vs $2g = 0.0800$（2.5 % の差 — 格子分解能 1 MHz と有限線幅によるディップ位置の引き寄せ）
- ホップフィールド係数 $0.500/0.500$、$g$ 感度 $1.000$（最大）
- $\text{splitting}/\kappa = 2.67 > 1$ ゆえ二つのディップが線幅で分解される

### 注入した効果

| 効果 | パラメータ |
|---|---|
| Fano | $q = 2.0$（複素位相方式） |
| TLS | offset $+0.005$ GHz、深さ $0.4$、線幅 $0.006$ GHz |
| tilt | slope $0.15$ |

### MCMC

`nwalkers=32`、`nsteps=25000`、`burn_in=5000`、`thin=10`、`seed=7`
prior: $f_r \in (4.8, 5.2)$、$g, \kappa \in (0.001, 0.50)$

### 4.2 baseline — パイプラインの検証

$0.0 / 0.1 / 1.5\%$ で参値を復元した。図では灰色（理想）・緑（歪み）・赤（フィット）の三曲線が完全に重なり区別できない。

**この行が clean であって初めて他の行の比較が成立する。** パイプライン自体の誤差床が約 1.5 %（主に $\kappa$）であることも意味する。

### 4.3 鎖長に対する頑健性

8000 ステップと 25000 ステップの比較。

| | 8000 | 25000 | 変化 |
|---|---|---|---|
| Fano $\kappa$ | 7.4 % | 7.3 % | −0.1 |
| TLS $\kappa$ | 8.0 % | 8.1 % | +0.1 |
| ALL $\kappa$ | 3.7 % | 3.3 % | −0.4 |

**収束基準を満たしていなかった 8000 ステップでも、推定値そのものはすでに安定していた。** 収束不足は不確実性推定を信頼できなくするが、中央値の位置を大きく揺さぶってはいなかった。

これは結果の頑健性を示すと同時に、**収束判定と推定値の正確性が別問題である**ことを示している。

### 4.4 $f_r$ — 最も正確に見えるが最も鈍感

全シナリオで 0.3 % 以内。共振周波数はディップ位置という強い観測量に直接結びついており、モデルが誤っていても大きく動かない。

**したがって $f_r$ の精度でフィッティングの成否を判断してはならない。** 最初の（誤った設定での）試験では $f_r$ が 0.1 % 精度であった一方、$g$ と $\kappa$ は 140 % / 233 % ずれていた。**最も見栄えのよいパラメータが最も誤設定に鈍感である。**

### 4.5 $g$ — 動作点が適切なら頑健

全シナリオで 1.2 % 以内。反交差では $g$ が二つのディップ間隔 $2g$ として直接観測されるため、歪みに強い。

$\Phi = 0$ の分散領域であれば、この値は prior に支配されていた。**動作点の選択が識別可能性を決定する**というのがこの項目の教訓である。

### 4.6 $\kappa$ — 歪みが集まる場所

唯一 5 % を超える。そして**方向が効果ごとに逆である**。

| 効果 | $\kappa$ 誤差 | 方向 |
|---|---|---|
| Fano | 7.3 % | 過小評価（0.02780） |
| TLS | 8.1 % | 過大評価（0.03242） |
| ALL | 3.3 % | 過大評価（0.03098） |

$\kappa$ は線幅パラメータであるため、モデルにない線形の歪みを吸収する唯一の経路となる。

**Fano の吸収機構** — データの二つのディップが歪みにより $4.960/5.040 \to 4.956/5.037$ と左へずれ、深さも左右非対称になった（左 0.49 / 右 0.57）。

標準モデルにはディップ深さを非対称にする手段が**一つしかない**。離調を 0 でなくしてホップフィールド係数を不均等にすることである。実際フィットは $f_r = 4.98757$ まで下がって $\delta = +0.0124$ を作り、その結果 $\cos^2\theta = 0.577$ / $\sin^2\theta = 0.423$ の非対称が生じた。

すなわち **Fano 非対称が $f_r$ 移動 → 離調 → ホップフィールド係数の非対称という経路で吸収された。** これが $f_r$ が 0.2 %（他シナリオの 0.0 % に対し）動いた理由でもある。パラメータ相関を通じて歪みが予期せぬ場所へ伝播した事例である。

**TLS の吸収機構** — $5.005$ GHz の狭いディップが二つの主ディップの間のピーク上に乗る。ピーク高さは二つのローレンツの重なりで決まるため、モデルは $\kappa$ を大きくして重なりを増やしピークを下げる。図で理想ピーク 0.875 に対しフィットピーク 0.855 として確認される。

**Tilt が無害だった理由** — 傾斜は乗算因子としてゆっくり変化するため、ディップ近傍ではほぼ定数である。ディップの局所的形状が変わらないので $\kappa$ が影響を受けなかった。残差は翼部にのみ残り、膨らんだ $\sigma$（3.02x）がそれを許容した。

### 4.7 相殺 — 同時測定だけでは過小評価する

Fano $-7.3\%$、TLS $+8.1\%$ であるのに ALL は $+3.3\%$ である。

単純和は $+0.8\%$ であるから、**線形重ね合わせでもない。** 三つの効果が非線形に混ざり部分的に相殺している。

ALL のみを見ていれば、個々の効果の大きさを**半分以下に過小評価**していた。**効果を一つずつ有効化する設計が不可欠である**ことの直接的な証拠である。

計画しているパラメータ空間の地図化においては、**相殺が起きる領域が存在する**という意味でもある。その領域では観測されたバイアスが小さくても個々の系統効果は大きい。

### 4.8 雑音推定も汚染される

| シナリオ | 推定 $\sigma$ | 参値比 |
|---|---|---|
| baseline | 0.0363 | 2.42x |
| Fano | 0.0829 | **5.52x** |
| TLS | 0.0365 | 2.43x |
| Tilt | 0.0453 | 3.02x |
| ALL | 0.0910 | **6.06x** |

adaptive 推定が共振構造と歪みの残差を雑音として吸収する。baseline ですら 2.4 倍である。

$\sigma$ を過大評価するとガウス尤度が広がり、**残差が大きくても統計的に許容される**。誤設定が $\chi^2$ や残差指標に現れなくなる二次的な原因である。

### 4.9 モデルの自由度設計が歪みの行き先を決める

五枚すべてで、赤い曲線がスキャン両端で正確に $1.0$ に収束する一方、データはそうならない。

| シナリオ | 左端 | 右端 |
|---|---|---|
| baseline | 1.00 | 1.00 |
| Fano | 0.96 | 1.05 |
| Tilt | 0.93 | 1.07 |
| ALL | 0.89 | 1.10 |

標準モデル `s21_anticrossing_model` には振幅スケール $a$ も baseline 傾斜のパラメータも存在せず、構造的に $|S_{21}| \to 1$ となる。

**この「追随できなさ」が逆説的に $f_r$ と $g$ の精度を守った。** baseline のずれを吸収する自由度がないため残差として残るしかなく、パラメータ側へ漏れ込まなかった。

裏を返せば、`Sij` のように $a$ と $\alpha$ を持つモデルでは同じ歪みがパラメータ側へ吸収され、**より大きなバイアスを生みうる。** 自由度を増やすことが常に安全とは限らない。

これは未検証の仮説であり、§6 の後続項目として残す。

## 5. 診断指標の評価

### 5.1 収束判定

個別シナリオ四つは 25000 ステップで $\tau < N/50$ を通過した。ALL のみ失敗している。

```
ALL:  tau = [172.1, 123.2, 643.2],  N/50 = 500.0
```

注目すべきは **$\kappa$ の $\tau$ が 8000 ステップの 426.6 から 25000 ステップの 643.2 へ、むしろ増大した**ことである。

$\tau$ が鎖長とともに増大するのは、通常**長い鎖で初めて遅いモードが現れた**という信号である。短い鎖ではそのモードを数回しか往復できず $\tau$ を過小評価する。つまり 8000 ステップの 426.6 自体が信頼できない値であった。

三つの歪みが重なることで $\kappa$ 方向に細長い事後分布の谷が生じた可能性がある。40000 ステップでの再実行により確認でき、そこでも $\tau$ が増大するなら鎖長ではなく事後分布の構造の問題であるから、walker 数を増やす必要がある。

### 5.2 収束フラグの信頼性

全シナリオで `converged: True` が出力されたが、ALL は $\tau$ 基準を満たしていない。**パイプラインの収束フラグと emcee 標準基準が一致していない。** フラグの判定ロジックを確認する必要がある。

### 5.3 残差ベースの指標

§4.8 の通り $\sigma$ が 2.4–6.1 倍に膨らむため、$\chi^2$ 系の指標は歪みを検出できない。

**視覚的検証が決定的であった。** 図で灰色・緑・赤を重ねて描くと、どこがずれているかが即座に見えた。数値だけでは到達できない情報であった。

## 6. 結論

1. **動作点の選択がパラメータ識別可能性を決定する。** 反交差で $g$ 感度が最大となり、復元誤差は全シナリオ 1.2 % 以内であった。分散領域では $(f_r, g)$ が縮退し、$g$ を prior が決めてしまう。

2. **モデル誤設定は $\kappa$ に集中する。** $f_r$ と $g$ が 1 % 前後を保つ一方、$\kappa$ のみ 5 倍以上大きな誤差を示した。$\kappa$ は $Q$ 系の報告値に直接伝播するため実務的影響が大きい。

3. **効果は相殺しうる。** Fano（$-7.3\%$）と TLS（$+8.1\%$）が同時に入ると $+3.3\%$ に見える。単純和（$+0.8\%$）でもない非線形な混合である。効果を個別に有効化する設計が不可欠である。

4. **最も正確に見えるパラメータが最も鈍感である。** $f_r$ の精度でフィッティングの妥当性を判断してはならない。

5. **モデルの自由度設計が歪みの行き先を決める。** baseline 自由度を持たないモデルでは、歪みが残差として残りパラメータを汚染しなかった。

6. **雑音推定そのものが誤設定に汚染され、その方向は誤設定を隠す側である。**

7. **収束判定と推定値の正確性は別問題である。** 収束基準未達の状態でも中央値は安定していた。逆に収束フラグが True でも標準基準を満たさないことがある。

## 7. 次のステップ

**直近**

- ALL を 40000 ステップで再実行し $\tau$ を確認。なお増大するなら walker を 64 へ
- シードを 5–10 個振り、$\kappa$ の 7–8 % が baseline の誤差床（1.5 %）の上に確実にあることを確認
- `result` 辞書のキーを確認し MAP を実際に計算する

**本研究方向**

- Fano・TLS・tilt を**含む拡張モデル**で同じデータをフィットし、参値を復元できるか確認
- 標準モデルと拡張モデルの差から生じるバイアスを **Fisher–Cutler–Vallisneri 形式論で解析的に予測**し、本試験の実測値と対照
- $q$、TLS 深さ・offset、tilt slope を掃引し、**バイアスが統計誤差を超える条件**をパラメータ空間上で特定。相殺領域の位置も併せて確認
- TLS 深さを現実的範囲（$0.02$–$0.15$）でも試験する。本試験の $0.4$ は極端である
- 振幅自由度 $a$ を持つモデル（`Sij` 系）で同じ注入を行い、歪みの行き先が変わるかを確認
